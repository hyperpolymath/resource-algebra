== Purpose

Digest-pinned container images for proof checkers, so that a proof receipt can
name the image its checker ran in (`NAME[:TAG]@sha256:<64 hex>`), as
PROOF-POLICY §8.2 (standards#1625) requires for PWG-1. First consumer:
resource-algebra (Agda 2.6.4.3, Lean 4.35.0).

== IS / IS-NOT (draft)

IS:: digest-pinned prover images for PWG-1 receipts, with the checker baked in,
a smoke test per image, and published provenance.
IS-NOT:: a place for proofs, theorems or policy. Policy stays in `standards`;
proofs stay in the repositories that own them.

== Layout

* `agda/Containerfile`: `debian:trixie-slim@sha256:a72b4433…` (digest checked
against the Docker Hub API on 2026-11-18 and pulled by digest locally), Debian
`agda-bin 2.6.4.3-1+b2` from a snapshot.debian.org timestamp.
* `lean/Containerfile`: same base, the upstream Lean 4.35.0 archive checked
against the SHA256 in resource-algebra's `proofs.yml`.
* `.github/workflows/build.yml` (listing below): build, smoke test, push to
`ghcr.io/hyperpolymath/prover-images/{agda,lean}`, print the digest in the job
summary, attest provenance. Pushes only off `pull_request`.
* `.github/dependabot.yml` (listing below): weekly base-digest and action bumps.

== How a consumer pins a digest

Read the `image:` line in the build job's summary (or
`docker buildx imagetools inspect ghcr.io/hyperpolymath/prover-images/agda:sha-<commit>`)
and paste `ghcr.io/hyperpolymath/prover-images/agda@sha256:<digest>`. Never pin
a tag alone. Confirm with `gh attestation verify oci://…@sha256:<digest>
--repo hyperpolymath/prover-images`.

=== `.github/workflows/build.yml`

[source,yaml]
----
# DRAFT, UNTESTED (actionlint only). Handoff from resource-algebra PN-7.
# SPDX-License-Identifier: MPL-2.0
name: Build prover images
on:
  push:
    branches: [main]
    paths: ['agda/**', 'lean/**', '.github/workflows/build.yml']
  pull_request:
    paths: ['agda/**', 'lean/**', '.github/workflows/build.yml']
  workflow_dispatch:
permissions:
  contents: read
jobs:
  build:
    name: Build ${{ matrix.image }}
    runs-on: ubuntu-latest
    timeout-minutes: 30
    strategy:
      fail-fast: false
      matrix:
        include:
          - image: agda
            checker_cmd: agda --version
            checker_expect: 'Agda version 2.6.4.3'
          - image: lean
            checker_cmd: lean --version
            checker_expect: 'version 4.35.0,'
    permissions:
      contents: read
      packages: write      # push to GHCR (not granted on pull_request runs, see push gate)
      id-token: write      # sign the provenance attestation
      attestations: write
    env:
      IMAGE: ${{ matrix.image }}
      REGISTRY_IMAGE: ghcr.io/hyperpolymath/prover-images/${{ matrix.image }}
    steps:
      # Only action refs with evidence: SHA from resource-algebra's actions.lock
      # (checkout v7.0.1; attest ref present there, its version NOT confirmed).
      # Docker is driven by plain `docker` commands so no unverified action SHA
      # is invented. Re-pin with the estate's tooling when the repo exists.
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          persist-credentials: false
      - name: Build
        run: |
          set -euo pipefail
          docker build --pull=false --file "$IMAGE/Containerfile" \
            --tag "$REGISTRY_IMAGE:candidate" "$IMAGE"
      - name: Smoke test the checker inside the image
        env:
          CHECKER_CMD: ${{ matrix.checker_cmd }}
          CHECKER_EXPECT: ${{ matrix.checker_expect }}
        run: |
          set -euo pipefail
          out="$(docker run --rm "$REGISTRY_IMAGE:candidate" bash -c "$CHECKER_CMD")"
          echo "$out"
          grep -F "$CHECKER_EXPECT" <<<"$out"
      - name: Log in to GHCR
        if: github.event_name != 'pull_request'
        env:
          GH_TOKEN: ${{ github.token }}
          GH_ACTOR: ${{ github.actor }}
        run: echo "$GH_TOKEN" | docker login ghcr.io -u "$GH_ACTOR" --password-stdin
      - name: Push and record the digest
        id: push
        if: github.event_name != 'pull_request'
        env:
          SOURCE_SHA: ${{ github.sha }}
          CHECKER_CMD: ${{ matrix.checker_cmd }}
          CHECKER_EXPECT: ${{ matrix.checker_expect }}
        run: |
          set -euo pipefail
          docker tag "$REGISTRY_IMAGE:candidate" "$REGISTRY_IMAGE:sha-$SOURCE_SHA"
          docker push "$REGISTRY_IMAGE:sha-$SOURCE_SHA"
          digest="$(docker inspect --format '{{index .RepoDigests 0}}' "$REGISTRY_IMAGE:sha-$SOURCE_SHA" | sed 's/.*@//')"
          case "$digest" in sha256:[0-9a-f]*) ;; *) echo "::error::no digest: $digest"; exit 1;; esac
          [ "${#digest}" -eq 71 ] || { echo "::error::bad digest length: $digest"; exit 1; }
          echo "digest=$digest" >> "$GITHUB_OUTPUT"
          {
            echo "## Prover image: $IMAGE"
            echo ""
            echo "- image: \`$REGISTRY_IMAGE@$digest\`"
            echo "- source commit: \`$SOURCE_SHA\`"
            echo "- smoke test: \`$CHECKER_CMD\` matched \`$CHECKER_EXPECT\`"
            echo "- consumer pin: \`container: image: $REGISTRY_IMAGE@$digest\`"
          } >> "$GITHUB_STEP_SUMMARY"
      - name: Attest build provenance
        if: github.event_name != 'pull_request'
        uses: actions/attest@508db95dd578ae2727ebd6217d5ba78e4fbda05d # version unconfirmed
        with:
          subject-name: ${{ env.REGISTRY_IMAGE }}
          subject-digest: ${{ steps.push.outputs.digest }}
          push-to-registry: true
----
