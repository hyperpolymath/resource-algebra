Statuses follow the estate taxonomy: PROVEN / TESTED / ASSUMED / DESIGNED /
OPEN. Every PROVEN line names the module that discharges it under
`--safe --without-K --no-libraries --double-check`.

== Build invariant

* All modules carry `{-# OPTIONS --safe --without-K #-}`; no postulates, no
  holes, no standard library. — PROVEN by `just check` (All.agda).
* Three expected rejections fail at their invalid declaration and for the
  intended reason (`min m n != max m n`, `p != zero`, `suc _ != zero`). —
  TESTED by `scripts/check.sh`.
